# 한국에서 살아남기

여덟 살 입학식부터 서른다섯 살 통장 잔고까지, 한국 인생 시뮬레이션 웹게임.

**▶ 플레이: https://taehuicho00.github.io/korea-survival/**

![한국에서 살아남기](og.png)

## 게임 소개
- **학창 시절 (8–19세)**: 방과후 · 저녁 · 주말 플래너로 학원, 운동, 예술, 게임, 알바를 배치합니다. 예산과 스트레스를 관리하며 수능 또는 꿈(아이돌 · 프로게이머 · 웹툰 등)에 도전합니다.
- **19세 진로 40가지**: 수능 등급과 쌓은 경험에 따라 의대, 체대, 사관학교, 재수 등으로 갈립니다.
- **어른 편 (20–35세)**: 전공과 자격증에 따라 열리는 **직업 102종**. 의사는 국가고시를, 미용사는 자격증을 따야 합니다.
- **운과 부메랑**: 로또 1등(814만분의 1), 코인, 청약, 전세사기, AI 구조조정. 학창 시절의 선택이 30대에 돌아옵니다.
- **35세 성적표**: 연봉 · 순자산 · 집 · 행복도, 네컷 앨범, 칭호 · 진로 · 직업 도감.

## 기술
- 순수 HTML · CSS · JavaScript 단일 파일 (빌드 도구 없음)
- 캐릭터 · 배경 일러스트 전부 코드로 생성한 SVG
- 저장은 브라우저 localStorage (서버 없음, 로그인 없음)
- 모바일 우선 반응형, 라이트 · 다크 모드

## 로컬 실행
`index.html`을 브라우저로 열면 됩니다.
